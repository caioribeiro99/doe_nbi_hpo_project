# Confirmatory claims and evidence

**This document is the only permitted source for headline numerical claims in the
manuscript.** Every figure below is read from a committed artifact when this file is
generated by `scripts/build_claims_map.py`. A claim that does not appear here does
not go in the paper.

**Provenance.** Protocol frozen at `xgboost-hpo-protocol-v3`
(`9b15ba7c9f99915f84f1863407479d729fe1badb`), before any result existed. Analysis
frozen at `xgboost-hpo-confirmatory-results-v1` (`a4f20ed`). Campaign: 120/120 units,
0 failures, 9h46m.

**Verification.** Five independent verifiers recomputed eleven headline claims from
the raw per-unit artifacts. The central contrast was additionally rebuilt from
`candidate_revalidation` rows through the frozen factor model with an independent
dominance filter and 2-D hypervolume sweep, reproducing all 480 published per-unit
values to `0.000e+00`. Nine claims reproduced exactly; **two were corrected, and both
were the author's** — see Claims 7 and 11.

**Conventions.** Paired by replication, R = 30 per dataset. Differences are
(second − first); `hv_ratio` larger is better, so positive favours the second arm.
Primary evidence is the descriptive triple — median difference with percentile
bootstrap interval, win fraction with Wilson interval, matched-pairs rank-biserial —
and the test is secondary. Holm correction is applied **within each dataset** over a
family of three contrasts. **Dataset is the generalization unit; there is no pooling.**

### Claim 5 — What differs mechanically between NBI-S and NBI-R

| **Estimand** | Two frozen quantities: (a) the anchor-injection control, which inserts NBI-R's empirical anchors into NBI-S's revalidated set and changes nothing else; and (b) the CHIM extent ‖Φ[:,0] − Φ[:,1]‖, which at q = 2 IS the CHIM segment the subproblems distribute targets along. |
| **Dataset role** | all four datasets |
| **Endpoint** | CORE-relative hypervolume ratio; recorded NBI diagnostics |
| **Reference** | CORE |
| **Effect estimate** | anchor-injection effect (control − NBI-S) median +0.0133 on MAGIC and +0.0000 on the other three, against full NBI-S→NBI-R gaps of −0.0741, −0.0192, −0.4093, −0.6932. | **Win / tie / loss** | not applicable — the control is a rescoring of an existing set, not a contest |
| **Uncertainty** | the control set is a **superset** of NBI-S's, so its effect is non-negative by construction; it is nonzero in 29/30 MAGIC units (max +0.1755) |
| **Multiplicity-adjusted inference** | within-dataset Spearman between the per-replication CHIM extent ratio and the per-replication hypervolume gap: MAGIC rho = -0.111; Adult rho = +0.683; Bank Marketing rho = +0.678; Spambase rho = +0.320 |
| **Machine-readable source** | `analysis/secondary_analysis.json` → `controls`; `analysis/nbi_r_chim_collapse.json`; `analysis/nbi_r_mechanism.json` |

**Allowed wording.** "Inserting NBI-R's empirical anchors into NBI-S's returned set moves the indicator by approximately zero on three of four datasets, while the full provenance change moves it substantially. **Prohibited stronger wording.** Do NOT state the CHIM contraction as a demonstrated cause. ## How to use this document

A numerical statement in the manuscript must trace to a claim above. If it does not
appear here, it is not established by this study and does not go in the paper.

Two claims on this page were **corrected after an independent verifier refuted the
author's version** (Claims 7 and 11). They are left in corrected form with the
withdrawn version named, because a claims map that records only the claims its author
got right is not a claims map.
