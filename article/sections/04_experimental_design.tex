\subsection{Optimization protocol}
\label{sec:exp-protocol}
\paragraph{Replicas and CV.} Each (dataset, algorithm) cell is
repeated for $R{=}10$ independent replicas; each replica fits a
stratified 5-fold cross-validation. Replica seeds are derived from a
single \texttt{seed\_base} (default $42$) so the protocol can be
re-played byte-for-byte. A subset of datasets where the v1 results
look interesting may be re-run at $R{=}30$ for a tighter confidence
interval before submission.

\paragraph{Methods.} Five HPO strategies under matched evaluation
budget: (i) the proposed DoE + true $N$-objective NBI; (ii) coarse
grid search; (iii) random search; (iv) Bayesian optimization
(scikit-optimize \texttt{BayesSearchCV}); (v) tree-structured Parzen
estimator (Hyperopt). A sixth ablation track runs the legacy
weighted-sum scalarization to quantify the methodological correction.

\paragraph{Budget.} The shared budget is the dissertation default
$B = \mathrm{DOE\_RUNS} + \mathrm{NBI\_EVAL\_K} = 88 + 50 = 138$
configurations, each evaluated under the same 5-fold CV. Benchmarks
are passed \texttt{--budget 0} (auto-fairness) so they receive the
same number of objective evaluations.

\paragraph{Quality metrics.} ROC-AUC, PR-AUC, F1 (binary) /
F1-macro (multiclass), balanced accuracy, MCC. Calibration metrics
where probability outputs are well-defined: Brier score and ECE.

\paragraph{Cost metrics.} Mean fit-plus-predict time per fold; total
optimization time; total wall-clock time per replica.

\paragraph{Statistical analysis.}
Paired comparisons within each dataset
(non-parametric \emph{Wilcoxon} or paired \emph{t} after
log-transform); cross-dataset comparison via Friedman test followed
by Nemenyi post-hoc with critical-difference plots, following
\citet{demsar2006statistical}. All $p$-values use Holm--Bonferroni
correction within each family of comparisons.

\paragraph{Cost discipline.}
Before launch, \texttt{doe-xgb estimate-cost --preset
article\_v1\_12\_datasets\_3\_algorithms\_10\_replicas} produces an
authoritative wall-clock and dollar-cost estimate. The campaign is
gated by a sign-off on this estimate to avoid burning compute on
mis-scoped runs.

\paragraph{Determinism.}
Headline tables use \texttt{tree\_method=exact} and
\texttt{n\_jobs=1} (article-track default); the determinism cost is
documented in \texttt{docs/METHODOLOGY\_DECISIONS.md} D13.

\paragraph{Reproducibility.}
Every replica writes a system-fingerprinted manifest, the full
Pareto front, the NBI sub-problem residuals, the MBPA trigger
diagnostics, and a long-format per-fold metric CSV. Aggregation
scripts regenerate Tables~\ref{tab:performance}--\ref{tab:cost} of
Section~\ref{sec:results}.
